# 🇮🇳 India Border War Monitor

**Live Geopolitical Border Intelligence Dashboard (Frontend Only)**  
A clean, interactive web dashboard focused on monitoring geopolitical tension and border incidents involving India and its neighboring countries.

🔗 **Live Demo:** https://india-border-war-monitor-by-hrishi.vercel.app/

---

## 🧠 Project Overview

The **India Border War Monitor** is a responsive, visually engaging dashboard designed to:

- Track border tension and incidents involving India
- Provide risk-level indicators for key neighboring countries
- Display interactive visualizations and incident feeds
- Present essential situational awareness in a modern UI

This is a frontend-only project built with **HTML, CSS, and JavaScript**, and uses mock JSON data for simulation.

## 🧩 Features

### 🔹 Dashboard Statistics Cards
Displays:
- Country name
- Risk level (Low / Medium / High)
- Last recorded incident
- Type of incident
- Border length (static data)

### 🔹 Interactive Map (Leaflet.js)
- Centered on India
- Border markers with popups showing risk and status
- Visual highlighting of border regions

### 🔹 Incident Feed
A scrollable timeline of recent simulated incidents with:
- Date
- Country
- Summary
- Severity indication

### 🔹 Visual Charts (Chart.js)
- Line chart showing tension trends
- Bar graph comparing risk levels across countries

### 🔹 UI / UX
- Modern dark theme
- Responsive layout
- Smooth animations
- Hover & interaction effects
